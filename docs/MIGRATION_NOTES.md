# Lightweight JSON Migration Notes

This version intentionally avoids an external backend framework. The app remains the owner of operations.

The app now has a lightweight config layer inside the `.mlapp`:

- `initializeConfigLiteLayer`
- `refreshConfigDrivenUI`
- `configSourceNames`
- `configSourceAddress`
- `configPacketTypeNames`
- `configPacketCode`
- `decodePayloadByDefinition`

Hard-coded source-to-address logic was replaced in:

- `buildPacketRequestCommand`
- `getCheckedSources`
- `getCheckedLoggerSources`
- `getSelectedControlSource`
- `getSelectedScheduleSource`
- `buildRawControlCommand`
- `sendPayloadToTarget`

Packet decoding now uses `config/commands.json` packet field definitions instead of packet-specific decoder functions.

App Designer still contains static component properties such as `mfc1Node_3`; those are generated by App Designer and can remain. Runtime source nodes are deleted and rebuilt from JSON during startup.
